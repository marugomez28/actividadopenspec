# Sistema de Reservas Académicas (SDD + OpenSpec)

Sistema web para la gestión de reservas de laboratorios, auditorios y salas de cómputo, desarrollado bajo el enfoque de Spec-Driven Development (SDD).

## Requisitos previos
* Node.js (v18 o superior)
* npm o pnpm
